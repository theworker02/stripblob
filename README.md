# stripblob

Strip CSV/TSV blob tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/stripblob/

## Install / run

```bash
git clone https://github.com/theworker02/stripblob.git
cd stripblob
node src/cli.js
node --test
```
